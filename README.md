# Student Daily Expense Tracker

A simple Java console application to track a student's daily expenses and compare them with the daily budget.

## Class Name

`StudentExpense`

## File Name

`StudentExpense.java`

## Features

- Accepts student details using `Scanner`
- Stores student name and expenses using instance variables
- Calculates total expense
- Calculates remaining amount
- Checks whether the expense is within the budget
- Calculates exceeded amount
- Displays budget status
- Displays a complete expense report
- Handles:
  - Within Budget
  - Budget Fully Used
  - Budget Exceeded
- Does not use a constructor
- Does not use the `this` keyword
- Does not allow negative budget or expense values

## Instance Variables

- `studentName`
- `dailyBudget`
- `foodExpense`
- `travelExpense`
- `studyExpense`
- `otherExpense`

## Methods

- `calculateTotalExpense()`
- `calculateRemainingAmount()`
- `isWithinBudget()`
- `calculateExceededAmount()`
- `getBudgetStatus()`
- `displayExpenseReport()`

## Input Order

1. Student name
2. Daily budget
3. Food expense
4. Travel expense
5. Study expense
6. Other expense
